# medieval-calendar-pascal
1980s Turbo Pascal project to print out calendar pages with medieval data

With thanks to [jdurno](https://github.com/jdurno) for recovering this!

A project from 1987. It began under CP/M on an Osborne 1 a couple of years before this, and moved to DOS.
